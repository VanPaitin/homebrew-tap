# VanPaitin Homebrew Tap

## uptimev

Show how long your machine has been running in a friendly format.

```sh
brew install VanPaitin/tap/uptimev
uptimev
```

Source and documentation: [VanPaitin/uptimev](https://github.com/VanPaitin/uptimev)

## Homebrew Bundle

```ruby
tap "VanPaitin/tap"
brew "uptimev"
```
